# Bosch eBike 25 km/h Limiter — Reed Interceptor

**Firmware rev 1.3** · Arduino-based · rear reed only, in-line · **no GPS, no
extra sensors**

> **TLDR:** this board sits between your rear reed switch and the Bosch
> SCU. It reads the real wheel speed from the reed pulse timing and feeds
> the SCU either **true speed** (PASS) or a **scaled-down fast mode**
> (SPEED MODE). A **safety reed switch picks the mode at runtime**:
> magnet near the reed = fast, magnet away = stock.
> **One flag (`USE_MODE_REED`) decides whether the safety reed is used at
> all.**

## What it is

The Arduino sits in-line in the existing rear reed → SCU cable. It reads
the wheel speed from the rear reed pulses and sends the modified signal
back to the SCU. **Only the reed is tapped** — no other Bosch line is
touched.

| Mode | What the SCU sees |
| --- | --- |
| **PASS** | true speed, unmodified (stock behavior) |
| **SPEED MODE** | above 25 km/h, reported speed follows `0.1 × real + 10` |

---

## How speed is measured

Pure reed switch pulse timing — the same math the Bosch SCU (likely) uses :

```
speed[km/h] = (1,000,000 / period[us]) × WHEEL_CIRC_MM / 1000 × 3.6

```

One pulse per wheel revolution; the pulse period converts to Hz, then to
km/h via the wheel circumference (`WHEEL_CIRC_MM`).

---

## The modes

SPEED MODE scales the reported speed above the knee:

```
reported = RAMP_SLOPE × real + RAMP_INTERCEPT       (when real > RAMP_KNEE)

```

| Real | Reported (SPEED MODE) |
| --- | --- |
| 25.0 | 25.0 |
| 25.1 | **~12.5** |
| 30 | 13 |
| 40 | 14 |
| 50 | 15 |
| 55 | 15.5 |
| 56 | 15.6 |

The reported speed stays below 25 for any real speed under 150 km/h, so
motor support **never cuts off** — the motor always stays in its sub-25
support band.

---

## The safety reed (2nd reed switch)

A second reed switch + magnet selects the mode at runtime:

| Safety reed (magnet) | Mode | Display | Motor support |
| --- | --- | --- | --- |
| **Near** (reed closed) | **SPEED MODE** | scaled: `0.1×real + 10` (56 → 15.6) | full (reported stays < 25) |
| **Away** (reed open) | **PASS** | true speed, stock | true |

The idea: SPEED MODE needs the magnet deliberately positioned. If someone
else rides the bike without the magnet positioned, PASS (stock) is active.

### Enable / disable the safety reed 

In `bosch_reed_interceptor.ino`, a single flag controls the safety reed —
flip it and re-flash:

```c
#define USE_MODE_REED true   // true  = use the safety reed (magnet picks the mode)
                             // false = safety reed ignored, always SPEED MODE (fast)

```

| Flag | Safety reed used? | Behavior |
| --- | --- | --- |
| **true** (default) | **YES** | runtime: magnet near = **fast (SPEED MODE)**, magnet away = **stock (PASS)** |
| **false** | **NO** | safety reed **ignored** → **always SPEED MODE (fast)**. The reed is never read and can be left unwired |

Disabling it means easier detection by you bigger brother. so please take your time WIRE IT IN and KEEP IT ON.

## How the slew works (why the speed doesn't snap)

SPEED MODE jumps the *reported* speed at the 25 km/h knee:

| Real | Reported |
| --- | --- |
| 25.0 | 25.0 |
| 25.1 | **~12.5** |

That's a ~12.5 km/h step. Without slew, the output pulse frequency would
drop ~12.5 Hz → ~1 Hz *instantly* (a hard jerk on the motor).
`SLEW_KMH_PER_S = 12` caps how fast the reported speed may move, so:

* crossing 25 **upward** → ~1 s "fake brake" (support tapers smoothly)
* coming back **under** 25 → ~1 s "fake accel" (support ramps back)

Theoretically this makes the SCU less likely to notice anything odd and drop a err
from a sudden speed-signal change.

## Wiring

```
rear reed (main):    terminal A -> REED_PIN (pin 2)
                     terminal B -> GND
safety reed (2nd):   terminal A -> KILL_PIN (pin 4)
                     terminal B -> GND
SCU side:            SCU_PIN (pin 3) drives the existing signal wire to the SCU;
                     Arduino GND -> SCU GND (add a 10k to 5V if the line floats)
Power:               Find the display power cable, tap into it, and use a step-down converter to supply regulated 5V to the Arduino

```

Notes:

* The code provides the pull-ups (if your bord supports it) for both reed inputs. If either signal
is inverted, flip `REED_ACTIVE_LOW` / `KILL_ACTIVE_LOW`.
* Keep the whole thing in a small **dry box**.
* Mount the safety reed + magnet wherever is handy: frame, handlebar, bag.
With `USE_MODE_REED = false` the safety reed can be left **unwired** —
the board never reads it.

## Configuration

Everything lives in `bosch_reed_interceptor.ino`:

| Constant | Default | What it does |
| --- | --- | --- |
| `REED_PIN` | 2 | rear reed signal input |
| `KILL_PIN` | 4 | safety reed signal input |
| `SCU_PIN` | 3 | output drive to the SCU |
| `REED_ACTIVE_LOW` | true | true = line goes LOW when the magnet is present |
| `KILL_ACTIVE_LOW` | true | same as above, for the safety reed |
| **`USE_MODE_REED`** | **true** | **true = safety reed picks the mode (magnet = fast, away = stock) · false = safety reed ignored, always SPEED MODE (fast)** |
| `WHEEL_CIRC_MM` | 2100.0 | wheel + tire circumference (mm) |
| `IN_PULSES_PER_REV` | 1 | magnets on the wheel (usually 1) |
| `OUT_PULSES_PER_REV` | 1 | fake pulses emitted per revolution (keep at 1) |
| `RAMP_KNEE` | 25.0 | where SPEED MODE scaling starts (km/h) |
| `RAMP_SLOPE` / `RAMP_INTERCEPT` | 0.1 / 10.0 | SPEED MODE: `reported = 0.1×real + 10` |
| `SLEW_KMH_PER_S` | 12.0 | max reported-speed change rate (km/h per second) |
| `OUT_PULSE_WIDTH_US` | 3000 | output pulse width in µs (clamped to period/3) |
| `OUT_OPEN_DRAIN` | true | true = open-drain reed mimic, false = push-pull drive |
| `USE_SERIAL` / `SERIAL_BAUD` | true / 115200 | serial monitor output |

## Internals (tweak rarely)

| Constant | Default | What it does |
| --- | --- | --- |
| `SPEED_ALPHA` | 0.5 | IIR smoothing factor on the per-period speed |
| `STOP_TIMEOUT` | 1500 µs | time after the last pulse before the estimate starts decaying |
| `STOP_DECAY` | 30.0 | decay rate of the estimate once the wheel is stopped (km/h per s) |
| `DEBOUNCE_US` | 3000 µs | debounce window for input edges |
| `KILL_DEBOUNCE_US` | 50000 µs | debounce window for the safety reed level |
| `MIN_PULSE_US` | 20000 µs | ignore input edges closer together than this |
| `MAX_OUT_HZ` | 40 | safety clamp on the emitted pulse rate |
| `MAX_DT_US` | 10000 µs | clamps loop dt so a stalled loop can't fire a pulse burst |
